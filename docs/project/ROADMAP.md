# MCPRelay v1 Roadmap

The authoritative executable sequence is `MASTER_IMPLEMENTATION_PLAN.md`. This file is the compact milestone view.

| Phase | Goal | Primary exit |
|---|---|---|
| P0 | compatibility/component selection | no unresolved protocol/auth blocker |
| P1 | Windows single-node E2E | remote MCP/ChatGPT can operate Windows tools |
| P2 | reliability + reproducible config | reconnect/restart + diagnosable deployment |
| P3 | Windows packaging | clean install/reboot/reconnect/uninstall |
| P4 | multi-node Windows | 2 nodes isolated/targetable without code changes |
| P5 | Linux parity | same public contract works on Linux |
| P6 | v1 qualification | full acceptance + minimalism + independent review |

All phases are pre-authorized. The development team may proceed autonomously when dependencies/exit evidence permit. Reviewer/Owner intervention is required only for architecture/risk escalation defined in `DEVELOPMENT_MANAGEMENT.md` or final project verification.

Post-v1 ideas such as UI, automatic enrollment/control plane, fleet database and update service are intentionally not on the committed roadmap; they require observed need.
